Where it’s going

The road beyond alpha

SiliPuTTY is ready for controlled testing while the foundation for a fuller terminal and network-operations workspace takes shape.

  1. 01

    Modern terminal rendering

    ConPTY-backed VT rendering, ANSI support, resize events, and better full-screen application behavior.

  2. 02

    Deeper connectivity

    Raw, Telnet, Rlogin, Serial, SSH forwarding, jump hosts, proxy routing, and host-key management.

  3. 03

    Better file and network workflows

    Integrated transfer tools, richer packet inspection, Wake-on-LAN, and optional RDP launching.

  4. 04

    A stronger ecosystem

    More appliance profiles, plugin capabilities, automated coverage, documentation, and polished releases.
